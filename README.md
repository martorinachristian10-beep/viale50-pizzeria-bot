# 🍕 Pizzeria Viale50 - Assistente AI WhatsApp & Web

Assistente Intelligente 24/7 per la **Pizzeria Viale50** (Comiso, RG).

## Funzionalità
- 💬 Chat Web e Webhook WhatsApp Twilio
- 🪑 Gestione e raccolta prenotazione tavoli
- 🛵 Ricezione ordini a domicilio e da asporto con impasti speciali (Classico 48h, Contemporaneo, Integrale)
- 📋 Dashboard Tablet Cassa in tempo reale (`/admin`)
- 🤖 Powered by Google Gemini (`gemini-3.8-flash`)

## Deploy su Render
1. Collega questo repository su [dashboard.render.com](https://dashboard.render.com).
2. Seleziona **Web Service** (o usa `render.yaml`).
3. Imposta la variabile d'ambiente:
   - `GEMINI_API_KEY`: La tua chiave API di Google AI Studio.
